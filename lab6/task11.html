Это архитектурный подход, при котором изменения состояния приложения автоматически приводят к обновлению узлов DOM-дерева на странице без необходимости перезагрузки структуры вручную.
Для оптимизации используют паттерн «Делегирование событий». Вместо навешивания EventListener на каждый элемент списка, вешается один общий слушатель на их родительский контейнер.
Использование innerHTML для вставки непроверенных пользовательских данных категорически запрещено в продакшене, так как это создает прямую XSS уязвимость. Рекомендуется использовать textContent.
