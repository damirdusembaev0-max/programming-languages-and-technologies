**Тема:** Создание простого одностраничного приложения (SPA) без фреймворков: навигация по вкладкам, динамическая подгрузка контента[cite: 1].

## 1. Цель и результаты обучения
Освоить построение одностраничного интерфейса с вкладками, обработкой событий и динамической сменой содержимого без полной перезагрузки страницы[cite: 1]. После выполнения работы студент должен уметь:
* Управлять объектной моделью документа (DOM)[cite: 1].
* Организовывать клиентскую навигацию[cite: 1].
* Хранить данные представлений в структурированных объектах и массивах JavaScript[cite: 1].
* Обрабатывать ошибки загрузки данных[cite: 1].

## 3. Структура проекта
Проект разделен на три независимых файла согласно требованиям[cite: 3]:
1. `index.html` — корневая разметка, содержащая шапку, навигационный блок с кнопками и контейнер вывода контента (`<main id="content">`)[cite: 1, 3].
2. `style.css` — стили оформления интерфейса, адаптивная верстка для узких экранов и визуальное выделение активной вкладки[cite: 3].
3. `app.js` — логика приложения: управление состоянием, обработка событий клика (`addEventListener`), динамическое создание элементов DOM и асинхронный обмен данными[cite: 1, 3].

# КОНТРОЛЬНЫЕ ВОПРОСЫ И ОТВЕТЫ

**8. Что означает SPA и чем оно отличается от многостраничного сайта?**  
* **Ответ:** SPA (Single Page Application) — это веб-приложение, которое работает в рамках одной HTML-страницы[cite: 1]. В отличие от многостраничного сайта, где каждый переход по ссылке заново загружает страницу с сервера, в SPA переключения разделов выполняются динамически на клиенте с помощью JavaScript[cite: 1].

**9. Как переключать вкладки без перезагрузки страницы?**  
* **Ответ:** С помощью добавления обработчика событий `addEventListener` на кнопки навигации. При клике старый контент очищается, а в контейнер программно вставляются новые узлы DOM для выбранного раздела.

**10. Как найти и изменить элемент DOM?**  
* **Ответ:** Для поиска используются методы `document.querySelector()` или `document.querySelectorAll()`. Изменение содержимого или внешнего вида выполняется через свойства элементов, такие как `textContent`, `innerHTML` или изменение стилей в свойстве `style`.

**11. Зачем нужен addEventListener()?**  
* **Ответ:** Метод предназначен для регистрации прослушивателя событий (например, клика мыши, отправки формы) на конкретном элементе интерфейса и запуска функции-обработчика при возникновении этого события.

**12. Для чего используются data-атрибуты?**  
* **Ответ:** `data-*` атрибуты позволяют безопасно хранить пользовательские метаданные непосредственно внутри HTML-элементов (например, `data-page="articles"`), к которым можно легко обратиться в JavaScript через свойство `element.dataset`.

**13. Чем textContent отличается от innerHTML?**  
* **Ответ:** `textContent` работает исключительно с текстовым содержимым и безопасен по отношению к XSS-атакам. `innerHTML` позволяет считывать или записывать разметку вместе с HTML-тегами[cite: 1].

**14. Как выделить активную вкладку?**  
* **Ответ:** Через добавление специального CSS-класса (например, `.active`) к выбранной кнопке навигации и удаление этого класса у остальных кнопок. В стилях для класса `.active` задается отличный визуальный вид.

**15. Как организовать данные нескольких разделов?**  
* **Ответ:** Данные можно хранить в виде структурированных объектов JavaScript (где ключи соответствуют страницам) или в виде массивов объектов (для списков статей, задач или товаров).

**16. Что делает fetch() и почему локальные файлы могут не загружаться через file://?**  
* **Ответ:** Функция `fetch()` отправляет асинхронные HTTP-запросы за ресурсами. Протокол `file://` блокирует выполнение таких запросов из-за политики безопасности браузеров (CORS), поэтому для работы с файлами требуется локальный HTTP-сервер[cite: 3].

**17. Как обработать ошибку загрузки данных?**  
* **Ответ:** С помощью конструкции обработки исключений `try...catch` совместно с асинхронными функциями (`async/await`), перехватывая сетевые сбои и выводя пользователю соответствующее сообщение.

**18. Как проверить доступность навигации с клавиатуры?**  
* **Ответ:** Проверку выполняют путем перемещения фокуса по интерактивным элементам страницы с помощью клавиши `Tab` и активации элементов клавишей `Enter`. Интерфейс должен иметь видимую индикацию фокуса.

**19. Какие преимущества и ограничения имеет SPA без фреймворков?**  
* **Преимущества:** высокая скорость работы, минимальный размер приложения, глубокое понимание нативной работы браузера и JavaScript.  
* **Ограничения:** при масштабировании код может усложняться в поддержке, отсутствует встроенная сложная реактивность и готовая маршрутизация (роутинг).
